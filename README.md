# 🧮 Simple & Smart Calculator

A modern, responsive calculator built with **HTML, CSS, and JavaScript** as part of my **CodeAlpha Frontend Development Internship**.

The project focuses on practicing JavaScript fundamentals, DOM manipulation, event handling, calculator state management, keyboard interaction, responsive design, and light/dark theme functionality.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 📊 Percentage calculation
- 🗑️ AC (Clear) functionality
- ⌫ DEL (Delete) functionality
- 🧾 Calculation history
- 🧹 Clear history
- ⌨️ Keyboard support
- 🌙 Dark mode
- ☀️ Light mode
- ⚠️ Division-by-zero error handling
- 📱 Responsive design for different screen sizes
- 🚫 Prevents invalid calculations such as `12 × =`

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling, CSS Grid, responsive design, themes, and transitions
- **JavaScript (ES6)** – Calculator logic, DOM manipulation, event handling, state management, and keyboard support
